# 🚗 Driver and Vehicle Licensing Department (DVLD) System

## 📝 Overview
The **Driver and Vehicle Licensing Department (DVLD)** System is a desktop-based enterprise application designed to simulate the core operations of a real-world motor vehicle department. Built with high software engineering standards, it demonstrates clean architecture, multi-tier design, and robust data integrity management.

## ✨ Key Features
* **People & User Management:** Comprehensive manageability for personal records, combined with fine-grained User Access Control (RBAC) and security practices.
* **Applications Management:** Streamlined workflow for applying, tracking, and completing local and international driving license applications (New, Renew, Replacement for Lost/Damaged).
* **Test Appointment Pipeline:** Manage test scheduling and evaluations across three distinct phases: Vision, Written, and Practical Driving tests.
* **License Issuance & Detention:** Enforces real-world business logic constraints for issuing, renewing, detaining, and releasing licenses.
* **Transactions & Financial Log:** Automated application fee calculations and audit tracking for all department services.

## 🛠️ Tech Stack
* **Language:** C# / .NET Framework
* **UI Framework:** WinForms / Guna UI 2
* **Database:** Microsoft SQL Server / T-SQL
* **Data Access:** ADO.NET
* **Architecture:** N-Tier Layered Architecture (DAL, BLL, PL)

## 📐 Software Design & Principles
* **Object-Oriented Programming (OOP):** Deep application of encapsulation, inheritance, and polymorphism.
* **Relational Database Design:** Normalized schema enforcing strict foreign key constraints and transactional consistency.
* **Clean Architecture:** Strict decoupling between UI controls and core business domain algorithms.
